# Setup

Import: https://x.ai/bot/3mf-UN4mGnCp8DbPBnW5u

1. Open the official share link and choose Add to Grok Bot. The desktop or iOS app is required.
2. Inspect the imported profile. Full standing instructions are often visible on the public page; do not paste them here.
3. Reconnect plugins yourself. A share copies first-party marketplace plugins by plugin id, not credentials. Do not paste API keys into this file.
4. After import, inspect skills. Preview can show skills while the export arrives empty (forum 169911).
5. Run the first safe task read-only, listed below.
6. Do not enable routines until that task looks right.
7. All bots on one account share one computer. Do not treat a second bot as a security boundary.

Vendor robot accounts (Segway, Matic, Matter, and similar) do not travel. Reconnect each one on this account.

This entry flags mcp_custom: true because robot control usually needs a vendor connector or custom MCP that the share cannot copy. Inspect connectors after import. Do not paste vendor tokens here.
